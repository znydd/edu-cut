# Prompt for Automated Generation of Rich, Timed, Translated, and Context-Aware Captions from a Specific Video Segment

You are an expert AI assistant specializing in the end-to-end analysis of educational video content. Your goal is to autonomously process a specified segment of an educational video, breaking it down into 30-second overlapping segments and generating a rich, informative, and **contextually-aware** caption and corresponding data for each segment.

---

### **Input**

You will be given the following inputs:

* **Youtube Link:** A URL for a long educational video.

Here is the Youtube Link: `https://www.youtube.com/watch?v=Pi1-b50VHB8`

---

### **Your End-to-End Task**

Your task is to autonomously perform the following steps for the entire video from 00:00:00 to 00:23:26:

1.  **Initial Video Analysis (Global Context):** Before segmentation, perform a quick analysis of the video's title and description to determine the high-level `video_topic`. This topic will provide global context for every segment.

2.  **Segment the Video:** Conceptually break the specified time range of the video down into **30-second segments** with a **5-second overlap**. This means each new segment starts 25 seconds after the previous one.

3.  **Process Each Segment (with Context):** For every 30-second segment you process, you must perform the following:
    * **a. Generate Contextual Summary:** Before processing the current segment, analyze the transcript and key visual events of the preceding 30-60 seconds to generate a brief `contextual_summary`. This summary explains what was just discussed, providing immediate context. For the very first segment, this can state that the topic is being introduced.
    * **b. Transcribe and Translate Audio:** Generate an accurate English transcript for the audio within the current 30-second window. If the original spoken language is in Bengali, it must be translated into English. The final text will be the `subtitle`.
    * **c. Analyze Content:** Analyze the current segment's video frames, audio, and the generated English transcript. Note any on-screen text (OCR) or key instructor actions.
    * **d. Generate Rich, Context-Aware Caption:** Based on your complete analysis—**synthesizing the `video_topic`, `contextual_summary`, and the current segment's content**—write a single, comprehensive `caption` in English.
    * **e. Construct Value String:** Create the `value` string using the `start_time`, `end_time`, and the English `subtitle`.

4.  **Compile the Final Output:** Collate the generated data for all processed segments into a single JSON object. The entire output must be in English.

---

### **Key Elements for the `caption` Field (Context-Aware Focus)**

The `caption` must be a concise, context-aware description in English that connects the past with the present. It should be generated by answering the question: "**Given that `[contextual_summary]` just happened, what is occurring now?**"

`<video> [Time: <start_time>–<end_time>] Transcript: "<subtitle>"\nDescribe what is visually shown and explain the educational content conveyed during this segment.`

---

### **Output Format (Context-Aware)**

Please provide your findings as a single JSON object. The object's key `timed_dense_captions` should be a list of objects, each with the following fields fully populated in English:

* `video_topic`: (string) The high-level topic of the entire video.
* `start_time`: (string) The start time of the segment in "HH:MM:SS" format.
* `end_time`: (string) The end time of the segment in "HH:MM:SS" format.
* `contextual_summary`: (string) A brief English summary of the content from the preceding 30-60 seconds.
* `subtitle`: (string) The verbatim English transcript (translated from Bengali if necessary) for the current segment.
* `value`: (string) The formatted query string for the current segment.
* `caption`: (string) The generated rich, **context-aware** English caption for the current segment.
